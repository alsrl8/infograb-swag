# n8n 스웩 수령 체크

상품별 수령 체크와 남은 수량을 공유하는 반응형 웹 앱입니다.

- 상품 16종: 수량이 명시된 스웩 45개, 스티커, 초콜릿 2종
- 사다리 순서대로 이름 선택 → 상품 카드 체크 → 헤더에서 저장
- 헤더의 양보 버튼으로 상품 선택 없이 넘기기
- 양보 / 부재 / 저장 순서의 헤더 버튼, 부재는 기존 선택을 유지하며 보류
- 카드를 누르면 기본 수령 완료, 선택한 카드 오른쪽 위에서 미수령 / 수령 완료 전환 후 저장
- 선택만 저장하면 노란색 미수령 표시, 수량은 확보
- 상품별 수령했어요 체크 후 저장하면 초록색 수령 완료
- 수령·양보 완료자는 이름 목록에서 초록색 표시
- 기존 수령 완료 기록은 마이그레이션 후에도 완료 상태 유지
- 데스크톱에서도 최대 480px의 모바일 화면 제공
- 상품 선택 취소는 같은 기기에서, 수령 상태 변경은 다른 기기에서도 가능
- Cloudflare D1 공유 저장, 10초마다 현황 갱신
- 원자적 수량 검사로 재고 초과 방지, 상품·이름 중복 방지

## 개발

`/summary`는 Daisy와 Penny를 위한 상품별 정리 페이지입니다. 추가 선택 가능한 수량,
수령자, 선택 후 미수령자와 Slack 희망 사항을 구분하며 운영 데이터는 변경하지 않습니다.
희망 사항은 `lib/summary.ts`에 출처와 함께 기록하며 재고를 확보하지 않습니다.
초콜릿·스티커처럼 총수량이 없는 상품은 잔여 수량을 추정하지 않습니다.
집계 검증은 `node --experimental-strip-types --test lib/summary.test.mjs`로 실행합니다.

Node.js 22.13 이상. `npm ci`, `npm run dev`로 실행합니다.
재고가 바뀌면 `lib/products.ts`와 재고 제한 트리거를 새 마이그레이션으로 함께 변경합니다.
`npm run db:generate`로 스키마 마이그레이션을 생성하고 `npm run build`로 빌드합니다.
D1 `DB` 바인딩과 마이그레이션이 필요합니다. Sites 배포 시 적용됩니다.

사다리 순서는 `lib/participants.ts`, 상품 목록은 `lib/products.ts`, 수령 API는 `app/api/receipts/route.ts`에 있습니다.
실제 수령 기록은 저장소에 포함되지 않습니다.

이 앱은 공개 수령 체크 보드입니다. 이름과 체크 현황은 방문자에게 공개되며,
로그인 없이 사용합니다. 취소 권한은 해당 브라우저에 저장한 무작위 키로 확인합니다.
사다리 순서를 강제하지 않으며, 기존 수령 사실을 임의로 추정하여 입력하지 않습니다.
